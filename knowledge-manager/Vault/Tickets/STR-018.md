# Problem

Should CameraController be a static utility like PathWalker or an instance?

# Lösung

Decision: CameraController is instance-based (non-static). Alternatives: instance-based (chosen) pro: multiple independent camera controllers, testable, no shared state; contra: requires a field to hold the instance. Static like PathWalker pro: simple access, no instantiation; contra: only one camera at a time, hard to test, and it couples consumers. Rationale: the goal is to support multiple automation systems (pathfinding, combat, mining) each with independent camera state.
