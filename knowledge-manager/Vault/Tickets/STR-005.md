# Problem

Why was the 4.5-block diagonal drop limit dead code, with drops capped at 4.0 instead?

# Lösung

Decision: check the drop distance (4.5 limit) before the same-level/step-up distance (4.0 limit). Alternatives: check dy >= -1 first (original) pro: simpler order; contra: the dy > 0 check at 4.5 was dead code, drops were capped at 4.0. Check dy > 0 first (chosen) pro: both limits apply correctly, 4.5 for drops and 4.0 for flat/step-up; contra: slightly less obvious order. Rationale: drops-first matches the original intent that drops should allow 4.5 diagonal distance. The more specific condition must be checked before the more general one.
