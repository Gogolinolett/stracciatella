# Problem

Should AngleUtil.isFacingTarget read its tolerance from a config or take it as a parameter?

# Lösung

Decision: AngleUtil.isFacingTarget takes the tolerance as a parameter instead of reading from a config. Alternatives: tolerance as a parameter (chosen) pro: flexible, no coupling to any config, reusable; contra: the caller must pass a value. Read from the CameraController config pro: encapsulated; contra: ties the utility to a controller instance and makes it less reusable. Read from a global config pro: simple; contra: couples to a specific config and is unusable by other modules. Rationale: different contexts need different tolerances - gap=2 uses 18 degrees, gap of 3 or more uses 36 degrees, and step-ups use 45 degrees.
