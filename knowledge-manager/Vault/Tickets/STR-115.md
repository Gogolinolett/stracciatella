# Problem

Beim Reisen (Restock-Journey) soll der Bot ab und zu zufaellig Linksklicks spammen wie ein gelangweilter Spieler - auch auf Bloecke, aber nie etwas abbauen und nie Mobs oder Spieler treffen.

# Lösung

TravelClicks (bot/humanize), von RestockBehavior.tickTravel getickt solange die Journey laeuft, gestoppt beim Ende der Reise und in abort. Pro Tick travelClickChance 0,004 fuer einen Burst von travelClickMin-Max 2-6 Klicks im Abstand 2-5 Ticks, ueber den Blunder-Schalter (in Tests aus, siehe [[STR-114]]). Ein Klick geht dorthin, wo das Fadenkreuz schon ist. LUFT: vanillas Miss - swing plus resetAttackStrengthTicker. BLOCK: kurzer Druck ueber BlockInteractor.startInteraction(ATTACK) und stopInteraction nach 1-4 Ticks, auf dem Draht START dann ABORT wie ein Tippen; Haltezeit gedeckelt, sodass der Abbau unter MAX_PROGRESS 0,5 bleibt (getDestroyProgress pro Tick); ein Block, den schon der erste Tick braeche (Gras, Blumen, Fackeln), und alles im Kreativmodus wird gar nicht geklickt. ENTITY im Fadenkreuz: nichts, auch kein Schwung - es wird nie attack aufgerufen, und ein Schwung auf einen Mob saehe aus wie ein verfehlter Schlag. Waehrend der Controller arbeitet (die Journey laesst ueber RoutePlacer Bruecken bauen) keine Klicks, und losgelassen wird nur, wenn BlockInteractor.currentTarget noch der eigene Block ist, damit ein Klick nie eine Controller-Interaktion beendet. VERWORFEN: KeyMapping.click auf keyAttack - vanillas startAttack wuerde eine Entity im Fadenkreuz angreifen, ohne dass man dazwischen filtern kann, und continueAttack haelt nur mit gegriffener Maus, sonst ABORT im selben Tick; ueber BlockInteractor unterdrueckt der MinecraftMixin das vorzeitige ABORT solange isMining. TEST Bot clicks on its way without breaking or hitting anything: Stein angetippt und stehen geblieben, short_grass nie gedrueckt, NoAI-Schwein im Fadenkreuz weder getroffen noch angeschwungen.
